# Data Model: Dashboard Upgrade

**Date**: 2026-01-09
**Branch**: `001-dashboard-upgrade`

> Current scope note (2026-04-24): the implemented dashboard is Binance spot-only. Older references to Upbit, futures, leverage, or liquidation fields are obsolete.

## Entities

### 1. Position

Represents an open spot position surfaced by the runtime and dashboard APIs.

| Field | Type | Description | Source |
|---|---|---|---|
| symbol | string | Asset symbol (for example `BTC`) | Runtime state |
| exchange | string | Always `binance` in the current runtime | Derived |
| side | string | Always `LONG` for active positions | Derived |
| quantity | float | Position size | Runtime state |
| entry_price | float | Average entry price | Runtime state |
| current_price | float | Latest market price | Feed-derived |
| value | float | Current position value | Calculated |
| unrealized_pnl | float | Unrealized profit/loss | Calculated |
| unrealized_pnl_pct | float | Unrealized P&L percentage | Calculated |
| opened_at | datetime? | Position open timestamp when available | Runtime state |

**Validation Rules**:
- `quantity > 0` for open positions
- `exchange == "binance"`
- `side == "LONG"`

### 2. Trade

Represents a completed spot trade from SQLite and JSON runtime logs.

| Field | Type | Description | Source |
|---|---|---|---|
| id | int | Auto-increment primary key | DB |
| strategy_id | int | Foreign key to strategies | DB |
| action | string | `BUY` or `SELL` | Trade logger |
| price | float | Execution price | Trade logger |
| volume | float | Trade quantity | Trade logger |
| profit | float? | Realized P&L for closing trades | Trade logger |
| profit_pct | float? | Realized P&L % for closing trades | Trade logger |
| exchange | string | Always `binance` in current runtime | Trade logger |
| timestamp | datetime | Trade execution time | Trade logger |
| strategy | string | Strategy name | JSON log |
| reason | string | Entry/exit reason | JSON log |
| regime | string | Market regime at trade time | JSON log |

### 3. Signal

Represents a strategy decision generated by the component engine.

| Field | Type | Description | Source |
|---|---|---|---|
| timestamp | datetime | Signal generation time | JSON log |
| strategy | string | Strategy name | JSON log |
| action | string | `buy`, `sell`, or `hold` | JSON log |
| reason | string | Signal reason code | JSON log |
| regime | string | Current market regime | JSON log |
| market_state | string | Detailed market state | JSON log |
| indicators | object | Technical indicators snapshot | JSON log |

### 4. AnalyticsPeriod

Represents aggregated performance metrics for a selected time period.

| Field | Type | Description | Calculation |
|---|---|---|---|
| period | string | `7d`, `30d`, `90d`, `all` | Input |
| start_date | date | Period start | Input |
| end_date | date | Period end | Input |
| total_return | float | Total return % | Calculated |
| total_return_usdt | float | Absolute return in quote currency | Calculated |
| win_rate | float | Winning trades % | Calculated |
| total_trades | int | Number of closed trades | Count |
| profit_factor | float | Gross profit / gross loss | Calculated |
| avg_trade | float | Average trade P&L | Calculated |
| sharpe_ratio | float | Risk-adjusted return | Calculated |
| max_drawdown | float | Maximum drawdown % | Calculated |
| avg_trade_duration | float | Average holding time (hours) | Calculated |
