# Data Model: Dashboard Upgrade

**Date**: 2026-01-09
**Branch**: `001-dashboard-upgrade`

## Entities

### 1. Position (Read-only from Exchange APIs)

Represents an open trading position on either exchange.

| Field | Type | Description | Source |
|-------|------|-------------|--------|
| symbol | string | Asset symbol (e.g., "BTC", "BTCUSDT") | Exchange API |
| exchange | string | "upbit" or "binance" | Derived |
| side | string | "LONG" or "SHORT" | Exchange API |
| quantity | float | Position size | Exchange API |
| entry_price | float | Average entry price | Exchange API |
| current_price | float | Current market price | Exchange API |
| value | float | Current position value | Calculated |
| unrealized_pnl | float | Unrealized profit/loss | Exchange API |
| unrealized_pnl_pct | float | Unrealized P&L percentage | Calculated |
| liquidation_price | float? | Liquidation price (Binance only) | Exchange API |
| leverage | int? | Position leverage (Binance only) | Exchange API |

**Validation Rules**:
- quantity > 0 for open positions
- exchange must be "upbit" or "binance"
- side must be "LONG" or "SHORT"

---

### 2. Trade (SQLite `trades` table)

Represents a completed trade stored in database.

| Field | Type | Description | Source |
|-------|------|-------------|--------|
| id | int | Auto-increment primary key | DB |
| strategy_id | int | Foreign key to strategies | DB |
| action | string | "BUY" or "SELL" | TradeLogger |
| price | float | Execution price | TradeLogger |
| volume | float | Trade quantity | TradeLogger |
| profit | float? | Realized P&L (SELL only) | TradeLogger |
| profit_pct | float? | Realized P&L % (SELL only) | TradeLogger |
| exchange | string | "upbit" or "binance" | TradeLogger |
| timestamp | datetime | Trade execution time | TradeLogger |

**Extended Trade (from JSON logs)**:

| Field | Type | Description | Source |
|-------|------|-------------|--------|
| strategy | string | Strategy name | JSON log |
| reason | string | Entry/exit reason code | JSON log |
| regime | string | Market regime at trade time | JSON log |
| indicators | object | Technical indicators snapshot | JSON log |

**Validation Rules**:
- action must be "BUY" or "SELL"
- price > 0
- volume > 0
- profit only set when action = "SELL"

**State Transitions**:
- Position opens with BUY action
- Position closes with SELL action (profit calculated)

---

### 3. Signal (JSON logs only, not persisted to DB)

Represents a trading signal generated by strategy.

| Field | Type | Description | Source |
|-------|------|-------------|--------|
| timestamp | datetime | Signal generation time | JSON log |
| strategy | string | Strategy name | JSON log |
| action | string | "buy", "sell", or "hold" | JSON log |
| reason | string | Signal reason code | JSON log |
| regime | string | Current market regime | JSON log |
| market_state | string | Detailed market state | JSON log |
| indicators | object | Technical indicators | JSON log |
| indicators.rsi | float | RSI value | JSON log |
| indicators.mfi | float | MFI value | JSON log |
| indicators.adx | float | ADX value | JSON log |
| indicators.close | float | Close price | JSON log |
| indicators.score | int | Composite score | JSON log |
| indicators.tier | string | Signal tier (S, A, B, etc.) | JSON log |

**Validation Rules**:
- action must be "buy", "sell", or "hold"
- timestamp must be valid ISO format

---

### 4. AnalyticsPeriod (Calculated, not persisted)

Represents aggregated performance metrics for a time period.

| Field | Type | Description | Calculation |
|-------|------|-------------|-------------|
| period | string | "7d", "30d", "90d", "all" | Input |
| start_date | date | Period start | Input |
| end_date | date | Period end | Input |
| total_return | float | Total return % | (final - initial) / initial |
| total_return_krw | float | Absolute return in KRW | final - initial |
| win_rate | float | Winning trades % | wins / total_trades |
| total_trades | int | Number of closed trades | Count |
| winning_trades | int | Profitable trades | Count |
| losing_trades | int | Unprofitable trades | Count |
| profit_factor | float | Gross profit / gross loss | sum(wins) / sum(losses) |
| avg_trade | float | Average trade P&L | sum(pnl) / total_trades |
| avg_win | float | Average winning trade | sum(wins) / winning_trades |
| avg_loss | float | Average losing trade | sum(losses) / losing_trades |
| sharpe_ratio | float | Risk-adjusted return | Calculated |
| max_drawdown | float | Maximum drawdown % | Calculated |
| max_drawdown_krw | float | Maximum drawdown amount | Calculated |
| avg_trade_duration | float | Average holding time (hours) | Calculated |

**Validation Rules**:
- period must be valid period string
- end_date >= start_date

---

### 5. EquityPoint (Calculated for charts)

Single point on equity curve.

| Field | Type | Description |
|-------|------|-------------|
| timestamp | datetime | Point in time |
| equity | float | Total portfolio value |
| cash | float | Cash balance |
| position_value | float | Open positions value |
| drawdown | float | Drawdown from peak |
| drawdown_pct | float | Drawdown percentage |

---

### 6. BacktestJob (In-memory only)

Represents a backtest execution job.

| Field | Type | Description |
|-------|------|-------------|
| job_id | string | UUID for job tracking |
| status | string | "pending", "running", "completed", "failed" |
| strategy | string | Strategy name to backtest |
| start_date | date | Backtest start date |
| end_date | date | Backtest end date |
| initial_capital | float | Starting capital |
| progress | float | Completion percentage (0-100) |
| created_at | datetime | Job creation time |
| completed_at | datetime? | Job completion time |
| result | BacktestResult? | Results when completed |
| error | string? | Error message if failed |

**State Transitions**:
```
pending -> running -> completed
                   -> failed
```

---

### 7. BacktestResult (In-memory only)

Backtest execution results.

| Field | Type | Description |
|-------|------|-------------|
| initial_capital | float | Starting capital |
| final_capital | float | Ending capital |
| total_return | float | Return percentage |
| total_trades | int | Number of trades |
| winning_trades | int | Profitable trades |
| losing_trades | int | Unprofitable trades |
| win_rate | float | Win percentage |
| profit_factor | float | Profit factor |
| sharpe_ratio | float | Sharpe ratio |
| max_drawdown | float | Maximum drawdown |
| trades | list[Trade] | List of executed trades |
| equity_curve | list[EquityPoint] | Equity over time |

---

## Relationships

```
Strategy (1) ----< (N) Trade
Trade (N) >---- (1) Exchange

Position (N) >---- (1) Exchange

Signal (N) >---- (1) Strategy

BacktestJob (1) ----< (1) BacktestResult
BacktestResult (1) ----< (N) Trade
BacktestResult (1) ----< (N) EquityPoint
```

## Data Volume Estimates

| Entity | Expected Volume | Retention |
|--------|-----------------|-----------|
| Position | 0-10 at any time | Real-time only |

| Signal | ~50 cached | Last 24h in JSON |

| BacktestJob | ~5 concurrent max | 1 hour TTL |
